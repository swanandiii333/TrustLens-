# 03. Objectives

## 1. Primary Objective

To develop TrustLens, an AI-assisted website trust and phishing risk analyzer that uses Machine Learning and URL-based cybersecurity analysis to identify potentially suspicious websites.

## 2. Specific Objectives

- Collect and preprocess phishing and legitimate URL data.
- Extract structural and lexical features from URLs.
- Develop and evaluate Machine Learning models for phishing detection.
- Build a final production Random Forest pipeline using 17 URL features.
- Generate phishing probability and a 0–100 risk score.
- Classify URLs as Legitimate, Suspicious, or Phishing.
- Provide understandable rule-based explanations.
- Provide practical security recommendations.
- Support QR-code URL analysis.
- Support screenshot-based URL extraction using OCR.
- Provide a Streamlit-based user interface.
- Generate PDF analysis reports.
- Test the system using legitimate, phishing, invalid, QR, and OCR inputs.
- Clearly document the limitations of URL-based phishing analysis.

## 3. Expected Outcome

The expected outcome is a functional cybersecurity application that demonstrates how Machine Learning and URL-based security analysis can be combined to provide an understandable phishing-risk assessment.

## 4. Conclusion

The objectives of TrustLens focus on developing a practical, explainable, and educational cybersecurity application while keeping the project scope centered on URL-based phishing risk analysis.
