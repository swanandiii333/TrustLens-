# 09. Project Timeline

## Purpose

This document presents the planned development schedule for the **AI-Powered Phishing URL Detection System**. The project is expected to be completed within one academic semester (approximately 16 weeks) while being developed part-time alongside regular BCA coursework.

The project follows a **Learn While Building** approach, where concepts are studied immediately before they are implemented.

---

# Development Timeline

| Phase | Duration | Activities | Deliverables |
|------|----------|------------|--------------|
| **Phase 1** | Weeks 1–2 | Project Planning & Documentation | Planning documents, project scope, requirements, architecture |
| **Phase 2** | Week 3 | Development Environment Setup | Python, VS Code, Git, GitHub, virtual environment, required libraries |
| **Phase 3** | Weeks 4–5 | Dataset Collection & Exploration | Dataset selection, EDA, dataset understanding |
| **Phase 4** | Week 6 | Data Preprocessing | Data cleaning, preprocessing, handling missing values, dataset preparation |
| **Phase 5** | Weeks 7–8 | Feature Engineering | URL lexical feature extraction module |
| **Phase 6** | Weeks 9–11 | Model Training & Evaluation | Train and compare ML models, evaluate performance |
| **Phase 7** | Week 12 | Model Finalization | Select best-performing model and save using Joblib |
| **Phase 8** | Weeks 13–14 | Streamlit Application Development | User interface, prediction pipeline, confidence score |
| **Phase 9** | Week 15 | Testing & Debugging | Functional testing, validation, bug fixing |
| **Phase 10** | Week 16 | Documentation & Project Finalization | Final documentation, GitHub update, report preparation, buffer time |

---

# Phase Details

## Phase 1 – Project Planning & Documentation (Weeks 1–2)

- Finalize project idea
- Define problem statement
- Prepare objectives
- Define project scope
- Conduct feasibility study
- Document requirements
- Design system architecture
- Select technology stack
- Prepare project timeline
- Perform risk analysis
- Identify future enhancements

**Deliverable:** Complete project planning documentation.

---

## Phase 2 – Development Environment Setup (Week 3)

- Install Python
- Install Visual Studio Code
- Install Git
- Create GitHub repository
- Configure virtual environment
- Install required Python libraries
- Verify development environment

**Deliverable:** Ready-to-use development environment.

---

## Phase 3 – Dataset Collection & Exploration (Weeks 4–5)

- Identify suitable phishing URL dataset
- Download dataset
- Study dataset structure
- Explore dataset using Pandas
- Analyze class distribution
- Understand feature columns

**Deliverable:** Clean understanding of the dataset.

---

## Phase 4 – Data Preprocessing (Week 6)

- Handle missing values
- Remove duplicate records
- Prepare dataset for Machine Learning
- Perform train-test split
- Validate dataset quality

**Deliverable:** Preprocessed dataset ready for feature engineering.

---

## Phase 5 – Feature Engineering (Weeks 7–8)

- Study lexical URL features
- Extract URL-based features
- Build reusable feature extraction module
- Verify extracted features

**Deliverable:** Feature extraction module shared by both training and prediction pipelines.

---

## Phase 6 – Model Training & Evaluation (Weeks 9–11)

- Train Logistic Regression
- Train Decision Tree
- Train Random Forest
- Compare model performance
- Evaluate Accuracy
- Evaluate Precision
- Evaluate Recall
- Evaluate F1-Score
- Generate Confusion Matrix

**Deliverable:** Performance comparison of all candidate models.

---

## Phase 7 – Model Finalization (Week 12)

- Select the best-performing model
- Save trained model using Joblib
- Verify model loading process

**Deliverable:** Production-ready trained model.

---

## Phase 8 – Streamlit Application Development (Weeks 13–14)

- Design user interface
- Create URL input page
- Connect feature extraction module
- Load trained model
- Display prediction results
- Display confidence score
- Improve usability

**Deliverable:** Functional Streamlit application.

---

## Phase 9 – Testing & Debugging (Week 15)

- Test valid URLs
- Test phishing URLs
- Test invalid URLs
- Test empty input
- Verify prediction accuracy
- Fix identified issues

**Deliverable:** Stable and tested application.

---

## Phase 10 – Documentation & Project Finalization (Week 16)

- Review project documentation
- Update final screenshots
- Complete GitHub repository
- Prepare project report
- Prepare viva notes
- Buffer time for revisions and unforeseen issues

**Deliverable:** Complete project ready for submission and demonstration.

# Timeline Summary

The project is planned over **16 weeks**, following a structured and incremental development process. Each phase builds upon the previous one, ensuring steady progress while balancing academic coursework. The inclusion of a dedicated testing phase and a final buffer week helps accommodate revisions, debugging, and unforeseen challenges before project submission.
